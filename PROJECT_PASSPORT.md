# Паспорт проекта: ISIC 2019 — бейслайн дерматоскопии

## Вход системы

- RGB-изображения дерматоскопии переменного разрешения.
- Возможные артефакты: пузырьки от геля, волосы, измерительные линейки, маркеры хирургов, виньетирование от линзы дерматоскопа.

## Выход системы

Вектор вероятностей по 8 классам (после Softmax):

| Индекс | Класс |
|--------|--------|
| 0 | Melanoma (MEL) |
| 1 | Melanocytic nevus (NV) |
| 2 | Basal cell carcinoma (BCC) |
| 3 | Actinic keratosis (AK) |
| 4 | Benign keratosis (BKL) |
| 5 | Dermatofibroma (DF) |
| 6 | Vascular lesion (VASC) |
| 7 | Squamous cell carcinoma (SCC) |

## Контекст применения

Инструмент **предварительного скрининга** с обязательным участием врача-дерматолога (human-in-the-loop). Система не заменяет клиническое решение.

## Критичность ошибок

- **Ложноотрицательный (FN)** по меланоме и злокачественным карциномам (MEL, BCC, SCC): критическая ошибка с точки зрения риска для пациента.
- **Ложноположительный (FP)**: допустимая ошибка в смысле последствий (направление на дообследование / биопсию), при этом всё равно требует клинической валидации порога и нагрузки на систему здравоохранения.

## Ограничения (стартовый бейслайн)

- Метаданные пациента (возраст, пол, локализация) **не используются** — только пиксели.
- Протокол обучения/валидации должен минимизировать **утечку** между train и val/test (сплит по `lesion_id` или `patient_id`, а не по отдельным кадрам одного поражения).

## Поддомены и гипотезы (аудит данных)

- Разные дерматоскопы и клиники → сдвиги в цвете, резкости, рамке кадра.
- Наличие волос на коже, тёмная/светлая кожа → возможный covariate shift и различный групповой риск.
- Сценарий «смартфон вместо дерматоскопа» в проде **не покрывается** официальным протоколом ISIC — это отдельный вопрос обобщения.

## Метрики и решения

- Агрегированная accuracy может быть обманчивой при дисбалансе (доминирование невуса).
- Для критичного узла «подозрение на меланома» используется **бинаризация** по вероятности класса MEL и подбор порога \(\tau\) с учётом асимметрии цен FP/FN (см. `reports/` после `evaluate`).
